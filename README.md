# 🚀 Integrated Tech Portfolio

> Satu sistem utuh yang dibangun bertahap — dari perencanaan, data, AI, cloud, keamanan, hingga antarmuka. Setiap project saling bersinggungan dan menumpuk menjadi satu produk nyata.
