## 1. Latar Belakang (Problem Statement)

Banyak organisasi kecil dan menengah punya data, tapi tidak punya alat untuk mengubah data itu menjadi keputusan. Data tersebar, tidak aman, dan sulit diakses. **SmartData Platform** dibangun untuk menjawab masalah ini: sebuah platform yang mengubah data mentah menjadi insight yang aman dan mudah diakses.

## 2. Tujuan Project (Objectives)

- Membangun pipeline yang dapat mengolah data mentah menjadi insight.
- Menambahkan kemampuan AI untuk analisis otomatis.
- Men-deploy platform ke cloud agar dapat diakses secara online.
- Memastikan platform aman sesuai praktik dasar keamanan siber.
- Menyajikan hasil melalui antarmuka web yang sederhana.

## 3. Ruang Lingkup Singkat (High-Level Scope)

**Termasuk:** pengolahan data, model/insight AI sederhana, deployment cloud dasar, kontrol keamanan dasar, antarmuka web minimal.

**Tidak termasuk:** skala enterprise, integrasi pembayaran, aplikasi mobile native.

## 6. Asumsi & Batasan

- **Asumsi:** dataset publik tersedia & gratis; layanan cloud free-tier mencukupi.
- **Batasan:** waktu (per hari satu fase); biaya (gunakan tier gratis).
