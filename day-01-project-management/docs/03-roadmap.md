# Roadmap & Timeline — SmartData Platform

Roadmap ini memetakan seluruh perjalanan portofolio. Setiap fase = satu "DAY". Fase saling bergantung: output satu hari menjadi input hari berikutnya.

---

## 🗺️ Peta Fase

```
[DAY 1] PERENCANAAN
   │  Charter, Scope, Risk → fondasi semuanya
   ▼
[DAY 2] DATA
   │  Dataset bersih + insight awal
   ▼
[DAY 3] AI
   │  Insight otomatis dari data DAY 2
   ▼
[DAY 4] CLOUD
   │  Deploy hasil DAY 2-3 agar online
   ▼
[DAY 5] KEAMANAN
   │  Amankan sistem yang sudah ter-deploy
   ▼
[DAY 6] WEB
      Antarmuka untuk mengakses semuanya
```

---

## 📅 Detail Fase

### Fase 1 — Perencanaan (DAY 1) ✅
**Tujuan:** Membuat cetak biru project.
**Deliverable:** Charter, Scope, Roadmap, Risk Register.
**Ketergantungan:** Tidak ada (titik awal).

### Fase 2 — Data Foundation (DAY 2)
**Tujuan:** Menyiapkan & menganalisis data.
**Deliverable:** Dataset bersih + notebook analisis + visualisasi.
**Ketergantungan:** Scope dari DAY 1.

### Fase 3 — Intelligence Layer (DAY 3)
**Tujuan:** Menambah kecerdasan AI di atas data.
**Deliverable:** Tool yang menghasilkan insight otomatis.
**Ketergantungan:** Data bersih dari DAY 2.

### Fase 4 — Deployment (DAY 4)
**Tujuan:** Membawa platform ke cloud.
**Deliverable:** Aplikasi yang bisa diakses lewat URL.
**Ketergantungan:** Aplikasi dari DAY 2-3.

### Fase 5 — Security Hardening (DAY 5)
**Tujuan:** Mengamankan sistem.
**Deliverable:** Audit keamanan + perbaikan.
**Ketergantungan:** Sistem ter-deploy dari DAY 4.

### Fase 6 — Presentation Layer (DAY 6)
**Tujuan:** Membuat antarmuka pengguna.
**Deliverable:** Web sederhana yang menyajikan hasil.
**Ketergantungan:** Seluruh fase sebelumnya.

---

## 🔄 Catatan Fleksibilitas

Antar-fase boleh berkaitan erat **atau** berdiri sendiri sebagai mini-project. Roadmap ini adalah panduan, bukan kontrak kaku — jika suatu hari kamu ingin mengeksplorasi topik lain (mis. Network Administration), cukup tambahkan sebagai cabang baru.
