# DAY 1 — Initiation (Inisiasi)

**Fase PMBOK:** Initiating · **Studi kasus:** TechFest Nusantara 2025

---

## 🎯 Tujuan Hari Ini

Tahap **inisiasi** adalah pintu gerbang sebuah project. Sebelum perencanaan detail dimulai,
kita harus menjawab: *Apakah project ini layak? Siapa yang mengesahkannya? Siapa saja yang terlibat?*

Saya berperan sebagai *Project Manager* yang menghasilkan tiga artefak inti inisiasi:

1. **Business Case** — argumen *mengapa* project layak dijalankan (analisis opsi & manfaat).
2. **Project Charter** — dokumen resmi yang *mengesahkan* project & wewenang PM.
3. **Stakeholder Register** — daftar pihak berkepentingan + strategi pengelolaannya.

## 🧠 Konsep Kunci yang Dipelajari

### Urutan logis dokumen inisiasi
```
Business Case  →  Project Charter  →  Stakeholder Register
(layak?)          (disahkan!)         (siapa terlibat?)
```

### Mengapa ini penting
- **Business case** mencegah project sia-sia: kita menilai opsi sebelum berkomitmen.
- **Charter** memberi PM wewenang resmi — tanpa ini, PM tak punya mandat.
- **Stakeholder register** mencegah kegagalan klasik: stakeholder penting yang terabaikan.

### Power–Interest Matrix
Alat memetakan stakeholder pada dua sumbu (pengaruh & minat) untuk menentukan
strategi: *kelola erat, jaga puas, jaga terinformasi,* atau *pantau*. Lihat visualnya
di README ini (dihasilkan dari `03-stakeholder-register.md`).

---

## 🎓 Istilah Penting

| Istilah | Arti |
|---------|------|
| **Business Case** | Justifikasi bisnis: apakah project layak secara nilai |
| **Project Charter** | Dokumen pengesahan resmi project |
| **Stakeholder** | Pihak mana pun yang terpengaruh / memengaruhi project |
| **SMART Objectives** | Sasaran yang Spesifik, Terukur, Achievable, Relevan, Time-bound |
| **Go/No-Go Gate** | Titik keputusan apakah project lanjut atau berhenti |
