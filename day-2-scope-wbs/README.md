## 🧠 Konsep Kunci yang Dipelajari

### Scope Creep — musuh nomor satu
*Scope creep* adalah pertumbuhan lingkup project secara tak terkendali. Scope statement
dengan daftar **Out-of-Scope** yang eksplisit adalah benteng pertahanannya. Setiap permintaan
tambahan harus lewat *change request* resmi, bukan langsung dikerjakan.

### WBS — "makan gajah sepotong demi sepotong"
Project sebesar event tidak bisa dikelola sebagai satu blok raksasa. WBS memecahnya
menjadi 8 paket kerja utama, lalu sub-paket, hingga *work package* — unit terkecil yang
bisa diestimasi. Lihat diagram pohonnya di README ini.

### Aturan 100%
WBS harus mencakup **100% pekerjaan** project — tidak lebih (tak ada pekerjaan di luar scope),
tidak kurang (tak ada yang terlewat). Antar-paket tidak boleh tumpang tindih.
